# Blank local feedback record

**No participant data has been collected in this file.** Copy the form to a
local working file for each teaching session or usability volunteer. Developed
with AI assistance as part of an unevaluated prototype.

Use an arbitrary participant code such as `V01` rather than a name. Keep raw
notes locally and outside the public repository. Use only the fictional
fixtures. Public issues must contain no student records, names, email addresses,
private manuscripts, client information, credentials or identifying file paths.
Review and redact any screenshot or pasted command output before sharing it.
Do not publish a participant's quotation without their agreement.

## Task observation

For the usability pilot, use task IDs T1 to T5 from the
[evaluation protocol](../docs/evaluation_protocol.md). For the teaching
session, use P1 to P4, paragraph revision and report discussion. Add rows as
needed. Distinguish what was observed from the observer's interpretation.

Completion codes: `I` = independent; `H` = completed after help; `B` = blocked
or incomplete after the time allowance; `N` = not attempted. A blank means
not yet recorded. Measure elapsed time consistently in whole minutes; it is
descriptive and not a productivity estimate.
