# Changelog

## Published source snapshot: 13 November 2026

The [RegNav archival source snapshot](https://github.com/Albertito-AI/policykit/releases/tag/archive-2026-11-13) records commit
`9e5f3f5a7c9da1c38a46fae5ce3b3efe4ac5b3ba` for preservation and citation.
This is a GitHub archival release of the existing source tree, **not** a new
versioned workbench distribution or production/customer acceptance. It adds no
binary release asset, changes no runtime version and grants no reuse licence.
The repository's `.zenodo.json` specifies closed archival files; an assigned
Zenodo DOI or completed external deposit requires separate confirmation.

## Unreleased: optional ESG workbench

- Added a separately invoked local ESG workbench without changing the core
  evidence-ledger schema.
- Added page-preserving PDF/text ingestion, optional OCR and table extraction,
  exact quotation locations, rule-based candidate extraction and local retrieval.
- Added explicit CSV/XLSX activity import, emissions arithmetic using supplied
  versioned factors, separate materiality screening perspectives and proposed
  accountable action plans.
- Added an opt-in model extraction adapter with source-quotation and literal-field
  checks. The checks do not establish factual correctness, and live model
  accuracy evaluation remains outstanding.
- Added offline HTML/Markdown/CSV/JSON views, compatible unreviewed ledger records
  and reproducible fictional examples. Domain interpretation and professional
  review remain human responsibilities.

## Unreleased: evidence-change and agent experiments

- Added [Source Watch](experiments/source_watch/README.md), an optional local
  byte-change observer for expressly listed files and supplied linked claim IDs.
  It cannot detect changes in unlisted sources or evaluate legal or factual truth.
- Added an optional [local MCP gateway](experiments/agent_gateway/README.md)
  exposing the operator-configured Source Watch observation through stdio. It
  does not provide a hosted service, payment authority or external-agent
  authentication.
- Added [evidence handover](experiments/evidence_handover/README.md), which maps
  one explicit RegNav-owned export contract into unreviewed core-ledger records
  while retaining separately validated supplied scope and process metadata.
  It composes recorded source/record/process and declared-inventory observations,
  exposes explicit unit, period, entity, boundary, anchor and assurance-set
  concerns, and retains version-linked review declarations without renewing
  or authenticating human review.
- Added a fictional handover demonstration, opt-in local MCP handover tool and
  eighteen disclosed internal synthetic engineering acceptance cases. These
  establish the tested software assertions, not compatibility with independent
  customer exports, semantic source verification, professional assurance or
  independently measured reviewer benefit.

The separately published [RegNav Source Watch Action](https://github.com/Albertito-AI/regnav-source-watch)
is an independent Apache-2.0 package with its own release history and manifest
contract. Its licence and v0.1.0 release do not change this repository's
[reserved rights](RIGHTS.md) or publish a policykit release.

## 0.1.0

Initial tracked research prototype: offline ledger creation and validation,
Markdown and CSV evidence matrices, explicit human-review declarations,
synthetic training material, regression tests and project documentation.

This version introduces no automatic legal-source verification, validated
legal dataset or claim of independent evaluation. Earlier starter archives
remain linked separately in the README.
